# Post Explorer

A simple, responsive web application that fetches and displays posts from the JSONPlaceholder API based on a selected user ID.

## Features

- Fetch posts from the JSONPlaceholder API.
- Search posts using a user ID between 1 and 10.
- Display post titles and content dynamically.
- Show the number of posts found.
- Display loading and error messages.
- Handle empty API responses.
- Validate user input before making requests.
- Disable the search button while loading.
- Responsive layout for desktop and mobile devices.

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Fetch API
- Async/Await
- URLSearchParams
- JSONPlaceholder API

## What I Practiced

- Making GET requests using Fetch API.
- Working with asynchronous JavaScript.
- Handling HTTP responses and errors.
- Using query parameters.
- Dynamically creating and updating DOM elements.
- Input validation.
- Implementing loading and error states.
- Responsive web design.

## API

This project uses the free [JSONPlaceholder API](https://jsonplaceholder.typicode.com/).

## Getting Started

1. Clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Enter a user ID between 1 and 10.
5. Click **Search Posts** to view the user's posts.
